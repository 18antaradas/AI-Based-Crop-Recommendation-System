# 🌾 AI-Based Crop Recommendation System

**Using Soil & Weather Monitoring (Smart Agriculture)**

AIoT-based smart agriculture system that recommends the most suitable crop from soil nutrients (N, P, K, pH) and weather data (temperature, humidity, rainfall). Uses a Random Forest classifier trained on the Kaggle Crop Recommendation Dataset, achieving ~99% accuracy across 22 crops. Built with Python, Scikit-learn, and Google Colab.

> Project for **Artificial Intelligence of Things (AIoT)** (MC470402), MCA 4th Semester, Department of Computer Science & Engineering, **NIT Patna**.

---

## 📌 Overview

Traditional farming often relies on experience and guesswork, leading to poor crop selection, overuse of water and fertilizers, and lower yields. This project combines **IoT-style sensor data** with **machine learning** so farmers can make data-driven decisions about what to grow.

Sensor readings (simulated here with a CSV dataset) are preprocessed and passed to a trained Random Forest model, which outputs the recommended crop.

```
IoT Sensors (N, P, K, Temp, Humidity, pH, Rainfall)
              ↓
   Data Preprocessing (Label Encoding)
              ↓
   Random Forest Classifier (AI Model)
              ↓
     Crop Recommendation Output
```

## 📊 Dataset

[Kaggle Crop Recommendation Dataset](https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset): **2,200 records**, **7 input features**, **22 crop labels** (100 samples per crop).

| Feature | Description |
|---|---|
| `N` | Nitrogen content in soil |
| `P` | Phosphorus content in soil |
| `K` | Potassium content in soil |
| `temperature` | Temperature (°C) |
| `humidity` | Relative humidity (%) |
| `ph` | Soil pH value |
| `rainfall` | Rainfall (mm) |
| `label` | Target crop |

**Crops:** Rice, Maize, Chickpea, Kidney Beans, Pigeon Peas, Moth Beans, Mung Bean, Blackgram, Lentil, Pomegranate, Banana, Mango, Grapes, Watermelon, Muskmelon, Apple, Orange, Papaya, Coconut, Cotton, Jute, Coffee.

## ⚙️ Workflow

1. **Load data** with Pandas and explore shape, types, missing values and statistics
2. **Visualize** crop distribution, feature correlation heatmap, temperature vs humidity scatter plot and feature boxplots (Matplotlib, Seaborn)
3. **Preprocess** by encoding crop labels with `LabelEncoder`
4. **Split** 80% train (1,760) / 20% test (440), `random_state=42`
5. **Train** `RandomForestClassifier(n_estimators=100)`
6. **Evaluate** with accuracy, classification report and confusion matrix
7. **Predict** a crop from custom soil and weather values
8. **Save** the model and label encoder with Joblib

### Option 2: Run locally

```bash

pip install pandas numpy scikit-learn matplotlib seaborn joblib jupyter
jupyter notebook AIOT_CROP_PROJECT.ipynb
```

> The notebook uses `google.colab.files.upload()` to load the dataset. When running locally, skip that cell and read the CSV directly with `pd.read_csv("Crop_recommendation.csv")`.

### Using the saved model

```python
import joblib
import pandas as pd

model = joblib.load("crop_model.pkl")
le = joblib.load("label_encoder.pkl")

sample = pd.DataFrame(
    [[90, 42, 43, 20.8, 82.0, 6.5, 202.9]],
    columns=["N", "P", "K", "temperature", "humidity", "ph", "rainfall"],
)

print(le.inverse_transform(model.predict(sample))[0])  # rice
```
